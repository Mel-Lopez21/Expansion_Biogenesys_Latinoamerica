# Informe Final de Consultoría: Biogenesys Farma 💊

## 📝 Introducción
Este informe detalla la expansión estratégica de Biogenesys en Latinoamérica, analizando variables epidemiológicas y demográficas para identificar la ubicación óptima de su nueva sede.

## 📊 Desarrollo del Proyecto
Se utilizó una metodología de **ETL** mediante Python (Pandas, NumPy) para procesar datos de organismos internacionales y el Banco Mundial.

### Conclusiones Técnicas:
* **Brasil:** Representa cerca del 50% de la demanda regional, justificando la inversión por economías de escala.
* **Chile y Argentina:** Mercados ideales para productos premium por su alto IDH.
